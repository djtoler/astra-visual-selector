# Astra Matching staged repair plan

**Proposal only — implementation requires editor review.** The filename retains “rebuild” from the audit brief; the recommendation is to repair and connect existing systems. No replacement renderer, catalog, registry, or new orchestration framework is proposed.

## Authorization and existing systems first

Recommended initial approval scope: **P0–P2 only**, then review before semantic/capability changes. Approval of this plan does not authorize native rendering, external provider spend, custom visuals, invented capability evidence or a new implementation outside existing supported workflows. Where a schema or runner capability is insufficient, first document the existing options and exact gap, then obtain approval for the specific extension.

Production baselines remain Matching `1276d0ca1daece81b5b7b38c8b5f5280046e5077` and Story `d5117a6de0fd0c640a336c6f456946ec8b40f319`. All repair runs write versioned outputs alongside frozen evidence.

## Required runtime order

validate source-bound Story/Data/Media contracts → materialize/reconcile semantic visual moments → derive one presentation contract and route → discover all relevant existing families/variants → assess specific permitted treatments and required meaning before truncation → retain explicit unknown/native review states → order and display a bounded review view with accessible full lineage → bind editor decisions to exact artifacts; use existing gated rendering only after separate authorization

Every stage receipt must bind exact input hashes, contract/catalog revision, output hash and unresolved states. Removing, reordering or changing a required stage invalidates downstream validated publication. A broad discovery view may be labeled unvalidated; it must not impersonate completed selection checks. Required native/human review remains explicitly pending until performed.

## Evaluation and promotion gates

Year Seventeen and Future are calibration/gold-reference material. Jay-Z/Drake is reviewed regression material. Preserve positive, negative, conditional and no-template cases; do not reuse prior picks as new-story admission rules. The wetland fixture remains unresolved/pending human approval, not end-to-end quality success. Use a new untouched package for independent quality acceptance.

- **positive_candidate_recall:** Recovered editor-accepted task+treatment alternatives / all adjudicated valid alternatives in the version-bound set. Report discovery, admission, reconciled and displayed recall separately; unknown native fit is a separate denominator. Gate: 100% on agreed critical regression alternatives; held-out minimum must be agreed before exposure.
- **negative_candidate_rejection:** Rejected incompatible task+treatment alternatives excluded at the appropriate stage / all adjudicated incompatible alternatives; report false exclusion of valid alternatives separately. Gate: 100% on explicit hard-constraint regression negatives; review subjective negative thresholds before evaluation.
- **family_and_variant_coverage:** Distinct compatible families/meaningfully different variants reached versus independently adjudicated expected set; same-family duplicate cards and hidden alternatives also reported. Gate: No silent loss of a validated alternative before display; display capacity is explicit, overflow remains accessible.
- **no_template_correctness:** Correctly preserved intentional no-template/clip/continuation routes and zero forced-template suggestions; separately test tasks wrongly suppressed from template discovery. Gate: All deterministic route fixtures pass; no-template does not claim media availability.
- **semantic_fidelity:** Exact span coverage, role/participant/unit/relationship preservation; separately adjudicated split/merge appropriateness. Gate: Zero omitted/invented narration and zero withholding violation; editorial segmentation judged with both split and keep counterexamples.
- **native_evidence_integrity:** False native-fit assertions; stale/missing mapping, timing, copy and asset evidence; unknown-to-rejected coercions. Gate: Zero unsupported native-fit claims and zero unknown-to-exhausted transitions.
- **review_effort:** Median/p90 review minutes, cards inspected, unresolved decisions and reopened cases per completed task, with coverage/quality held constant. Gate: Baseline to be measured; editor sets improvement target before rollout, no invented time savings.
- **generalization_and_reproducibility:** Same-artifact replay identity, provider response validation, subject-name paraphrase/renaming checks and genuinely untouched package quality. Gate: Deterministic fixtures and dependency hashes pass; quality thresholds frozen before held-out review.
